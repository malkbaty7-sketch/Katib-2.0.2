# Required GitHub repository secrets for Android APK build
# Add these values in GitHub -> Settings -> Secrets and variables -> Actions

# 1) KEYSTORE_BASE64
# Base64-encoded contents of your release keystore file (.jks)
# Example:
# openssl base64 -A -in my-upload-key.jks
#
# This secret is used by .github/workflows/build_apk.yml to generate the keystore
# before running assembleRelease.

# 2) STORE_PASSWORD
# Password for the keystore file.
# Example: myStrongPassword123

# 3) KEY_PASSWORD
# Password for the key alias inside the keystore.
# Example: myStrongPassword123

# 4) GEMINI_API_KEY (optional for build, required for AI features at runtime)
# Used by the backend/server and client-side AI logic.
# Example: AIza...your_key_here

# 5) GOOGLE_SERVICES_JSON (optional if Firebase is needed)
# Content of app/google-services.json if your app uses Firebase services.
# This file is usually required by Firebase configuration.

# 6) FIREBASE_API_KEY / FIREBASE_PROJECT_ID / FIREBASE_APP_ID (optional)
# Only if your Firebase setup requires extra values outside the google-services.json file.

# Notes:
# - Debug APK workflow does NOT require KEYSTORE_BASE64 / STORE_PASSWORD / KEY_PASSWORD.
# - Release APK workflow requires the keystore secrets above.
# - AI functionality will not work without GEMINI_API_KEY.
